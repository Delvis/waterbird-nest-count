# Lake Urema Waterbird Nest Counting (2026 Season)

## Overview
This repository contains a modular R pipeline for processing and visualizing waterbird nesting data at Lake Urema. The analysis tracks colony health, species diversity, and spatial distribution using field counts and GPS trackways.

## Analytical Pipeline

### 1. Data Processing (`01_basic_stats.R`)
* Cleans raw Excel field data and fixes timestamp epochs.
* Standardizes species mapping (codes to common names).
* Merges current 2026 data with historical monitoring records (2014–2026).

### 2. Ecological Visualization (`02_figures.R`)
* **Trend Analysis**: Total colony and species-specific trends over time.
* **Community Metrics**: Shannon Diversity ($H$) and cluster analysis of nesting seasons.
* **Nesting Strategy**: Tree occupancy vs. total abundance using linear modeling.

### 3. Spatial Survey Dynamics (`03_trackways.R`)
* Processes GPX trackways to segment the survey into 6 distinct phases (e.g., "Counting Survey," "Colony Extent Check").
* Calculates movement velocity (km/h) with rolling-mean smoothing to analyze survey effort.

### 4. General Nest Intensity (`04_heatmap_general.R`)
* Generates a community-wide heatmap of nest density.
* Uses Kernel Density Estimation (KDE) and a displacement vector to project boat-based sightings toward forest centroids.
* Visualizes "Sampling Effort" as the inverse of boat velocity.

### 5. Species-Specific Heatmaps (`05_heatmaps_per_species.R`)
* An automated loop that generates individual abundance maps for every species in the survey.
* Overlays raw observation "bubbles" (boat position) with estimated nest heat (tree position).

## 4. Species-Specific Heatmaps
This section provides a detailed spatial breakdown of the Lake Urema waterbird colony for the 2026 season. These visualizations are generated by `scripts/05_heatmaps_per_species.R`, which matches boat-based sightings to the nearest nesting trees using a temporal window and spatial displacement vector.

### Survey Methodology
Each map displays two layers of data:
1. **Observation Bubbles**: Raw nest counts at the boat's GPS position during the survey.
2. **Estimated Heat**: Projected nesting intensity within the flooded forest, calculated using Kernel Density Estimation (KDE).

## Requirements
  
To run the R scripts, you will need the following libraries:
  
- `readxl`
- `tidyverse` (includes `dplyr`, `ggplot2`, `lubridate`, `readr`, `tidyr`)
- `janitor`
- `ggthemes`
- `ggrepel`
- `ggdendro`
- `scales`
- `sf`  
- `patchwork`
- `zoo`
- `ggspatial`  
- `spatstat`
- `stars`

Install them in R using:
  
```r
install.packages(c("readxl", "tidyverse", "janitor", "ggthemes", "ggrepel", 
                   "ggdendro", "scales", "sf", "patchwork", "zoo", 
                   "ggspatial", "spatstat", "stars"))
```
